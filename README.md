# 뉴스 키워드 모니터 모바일 앱

네이버/카카오 API 없이 휴대폰에서 쓰는 키워드 검색용 PWA입니다. 앱에 키워드를 저장해두고, 매일 08:00, 12:00, 18:00 기준으로 검색 링크 목록을 갱신합니다.

## 현재 버전에서 하는 일

- 휴대폰 홈화면에 추가해서 앱처럼 사용
- 주제별 키워드 추가/삭제
- 키워드별 네이버 뉴스 최신순 검색 링크 생성
- 매일 3회 갱신 슬롯 표시: 08:00, 12:00, 18:00
- 앱이 열려 있을 때는 슬롯 시간이 바뀌면 자동 갱신
- 앱을 나중에 열면 놓친 슬롯을 기준으로 즉시 갱신
- 모든 설정과 갱신 기록은 휴대폰 브라우저 저장소에 보관

## 중요한 제한

이 버전은 네이버 검색 API를 호출하지 않습니다. 따라서 앱이 직접 새 기사 개수나 중복 기사를 판별하지는 않습니다. 대신 각 키워드의 네이버 뉴스 최신순 검색 화면으로 바로 이동하게 합니다.

모바일 브라우저/PWA는 앱이 완전히 닫힌 상태에서 매일 3번 반드시 깨어나는 동작을 안정적으로 보장하지 않습니다. 앱이 열려 있거나 다시 열릴 때 갱신 슬롯을 반영하는 방식입니다.

## GitHub에 올린 뒤 Pages로 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 전체를 저장소에 올립니다.
3. 저장소 `Settings > Pages`로 이동합니다.
4. `Build and deployment`의 `Source`를 `GitHub Actions`로 설정합니다.
5. `Actions > Deploy Mobile App > Run workflow`를 실행합니다.
6. 배포가 끝나면 GitHub Pages URL이 생성됩니다.

휴대폰에서 그 URL을 연 뒤:

- 아이폰 Safari: 공유 버튼 > `홈 화면에 추가`
- 안드로이드 Chrome: 메뉴 > `홈 화면에 추가`

## 키워드 수정

앱 안의 `키워드` 탭에서 수정합니다. 키워드는 쉼표 또는 줄바꿈으로 구분합니다.

기본 키워드:

- 가축전염병
- 가축전염병예방법
- 구제역
- 아프리카돼지열병
- 고병원성조류인플루엔자
- 럼피스킨
- 수의사

## 나중에 확장 가능한 기능

아래 기능은 네이버/카카오 API 또는 별도 서버가 필요합니다.

- 실제 새 기사 자동 수집
- 기사 중복 제거
- 카카오톡 자동 전송
- 앱이 닫혀 있어도 서버가 매일 3번 검색

현재 저장소에는 이전에 만든 `news_watch/` 서버 코드도 남겨두었습니다. 나중에 API 키를 준비하면 다시 연결할 수 있습니다.
